# Кузня Владений · Ordos

Публичный предварительный сайт кампании Age of Sigmar 4e.

## Что работает
- Карта 16 территорий с демо-редактированием контроля.
- Правила кампании (предварительная редакция).
- Участники, отдельные поединки 1v1 по 2000 очков, личные и командные рейтинги.
- Хроника шести двухнедельных циклов.
- Адаптивная верстка.

## Безопасность и ограничения

**Ни паролей, ни токенов, ни каких-либо административных секретов в репозитории нет.** Кнопка «Демо-редактор» — только локальный режим и НЕ авторизация. Изменения сохраняются в localStorage браузера, другие посетители их не увидят. Для реального публичного редактирования только двумя администраторами понадобится Supabase Auth/аналогичный защищённый сервис, серверные политики доступа (RLS) и база данных.

Прежде чем включить совместное редактирование, необходимо настроить аутентификацию, проверки ролей и политики изменения каждой таблицы. Профиль VK не заменяет аутентификацию.
